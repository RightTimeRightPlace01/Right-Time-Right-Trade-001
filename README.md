# Right-Time-Right-Trade-001

This repository contains small experiments with the `polygon-api-client`.

The `request.py` script demonstrates how to retrieve aggregates, trades and
quotes for a ticker symbol using `polygon`'s `RESTClient`.

Install the dependency:

```bash
pip install polygon-api-client
```

Run the script after setting your API key inside `request.py`:

```bash
python request.py
```
